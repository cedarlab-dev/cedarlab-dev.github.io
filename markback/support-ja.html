Markback / 最終更新日: 2026 年 10 月 25 日

Markback は、スクリーンショットに丸などの印と一言 (音声または文字) を付け、 「AI へ渡す」で report.md と注釈付き PNG のフォルダとして書き出すアプリです。 書き出したフォルダを Claude Code や Codex などの AI コーディングエージェントに読ませることで、 自分のアプリの直したいところをそのまま伝えられます。

よくある質問

Q. 書き出したフォルダが Mac に出てきません

iCloud Drive へ書き出した場合は、iCloud の同期が終わるまで時間がかかることがあります。 しばらく待っても表示されない場合は、以下をご確認ください:

  • iPhone と Mac が同じ Apple ID でサインインしているか
  • 両方の端末で iCloud Drive がオンになっているか
  • ネットワークに接続されているか

急ぎの場合は、渡した後の画面の「AirDrop で Mac に送る (zip)」を使うと、同期を待たずに Mac へ渡せます。 手順はアプリ内の「Mac での開き方」にも載っています。

Q. Claude Code や Codex にはどう渡しますか?

書き出したフォルダを Mac に置いたら、直したいアプリのプロジェクトのフォルダで Claude Code / Codex を開き、「AI への依頼文をコピー」でコピーした依頼文を貼り付けてください。 エージェントがフォルダ内の report.md と注釈付き PNG を読んで、指摘の内容を把握します。

毎回の手間を減らしたい場合は、アプリ内の「Mac での開き方」→「毎回の手間を減らす (/markback)」で設定文をコピーし、 Claude Code (または Codex) に 1 回だけ貼ってください。次からは /markback (Codex は $markback) と打つだけで、 iCloud Drive に届いた最新の指摘を読みます。

Q. 購入を復元したい

機種変更や再インストールの後は、アプリ内の 設定 > プラン > 購入を復元 から買い切りプランを復元できます。購入時と同じ Apple ID でサインインしている必要があります。

返金は Apple の返金ポリシーに従って Apple が処理します。 Apple のサポートページから直接申請してください: https://reportaproblem.apple.com

Q. データを削除したい

アプリ内の操作で、指摘・渡した指摘・対象アプリを個別に削除できます。 アプリを削除すると、端末内の本アプリのデータは消えます。

すでに書き出したフォルダは書き出し先 (iCloud Drive、ファイル App、選んだフォルダ等) に残ります。 不要な場合は、書き出し先からご自身で削除してください。
