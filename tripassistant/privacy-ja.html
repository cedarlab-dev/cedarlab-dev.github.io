旅アシ (TestFlight β 0.1.x) / 最終更新日: 2026 年 8 月 12 日

「旅アシ」(以下「本アプリ」) は、ご利用者のプライバシーを尊重します。 本ポリシーでは、本アプリがどのような情報を取り扱うかを説明します。

要旨

本アプリはアカウント登録を必要とせず、旅程データはお客様の iPhone の中だけに保存されます。開発者はサーバー上に旅程データベースを持たず、旅程の内容を 取得・閲覧することはできません。

このバージョンで自動的に発生する外部通信は、次の 2 種類です。

  1. 気象庁から天気予報・警報注意報・雨雲の画像を取得するとき
  2. 地図・地点 (POI)・経路のデータをダウンロードするとき

いずれも、送るのは「どのデータが欲しいか」(区域コード・タイルの位置・ファイル名) だけで、 旅程の内容・お客様を識別する情報は含めていません。

このほか、利用者が「Appleマップで渋滞・ナビ」を押したときだけ、選択した目的地の座標を Appleマップへ引き渡します。詳しくは第 3 項をご覧ください。

1. 収集する情報・収集しない情報

1.1 端末内で取り扱い、開発者が取得しない情報

以下は iPhone 内のデータベース (SQLite) またはアプリ専用ファイルで取り扱い、 開発者が旅程を受け取るデータベースや API には送信されません。 旅行中に取得した現在地は保存せず、その場の計算だけに使います。

  • 旅程 (旅行名、日程、訪問地点、順序、滞在時間、到着予定時刻、メモ)
  • 候補プール (雨天候補、予備候補、飲食店の第 1〜3 候補) と優先度設定
  • 宿泊・予約情報 (予約番号、チェックイン時刻、最終チェックイン、キャンセル期限、キャンセル料、電話番号、メモ)
  • 旅行中の進捗記録 (到着・出発の記録、遅れ、再計画の履歴)
  • 位置情報 (第 2 項)
  • ダウンロード済みの地図・地点 (POI)・経路データ、気象データのキャッシュ

アプリを削除すると端末上のデータは消去されます。事前に書き出したバックアップ、または iOS 標準のバックアップが利用できる場合を除き、開発者が復元することはできません (第 7 項)。

1.2 開発者が取得する情報

このバージョンでは、開発者が旅程の内容を取得する仕組みを設けていません。 アカウント登録がなく、旅程を受信・保存する開発者のデータベースや API もありません。 地図等の静的データ配信には cdn.cedarlab.dev を使用します (第 3 項)。

  • 氏名・メールアドレス・電話番号・Apple ID・支払い情報を本アプリから自動取得しません。
  • 通信の性質上、接続先の各事業者 (第 3 項) では IP アドレスなどの技術情報が処理されます。本アプリはこれらを利用者情報として収集・保存しません。各事業者側の取り扱いは各社のポリシーに従います。
  • TestFlight (Apple のベータ配布) についての注意: TestFlight でお試しいただく間、Apple の仕組みを通じてクラッシュ時の記録や、 テスターの方がご自身の操作で送信されたフィードバック (スクリーンショット・コメント) が開発者に届くことがあります。これは Apple が提供する 配布・テストの仕組みによるもので、本アプリが送信しているものではありません。 詳しくは Apple のプライバシーポリシーおよび TestFlight の説明をご参照ください。 なお、フィードバックにスクリーンショットを添付すると、画面に写っている旅程の内容 (行き先・日付・宿泊先の名称など) がそのまま開発者に届きます。写したくない内容がある場合は、 添付せずコメントだけをお送りください。

1.3 解析・広告

第三者の解析 SDK・広告 SDK・トラッキング SDK を組み込んでいません。 App Tracking Transparency の許可を求めることもありません (トラッキングを行わないため)。

2. 位置情報

  • 取得は 「アプリの使用中のみ (When In Use)」 に限定します。バックグラウンドでの継続取得・常時許可は求めません。
  • 用途は、旅行中の「現在地の表示」「次の目的地までの残り時間の計算」「現在地を起点とした再計画」です。
  • 取得した位置情報は端末内で処理し、開発者のサーバーへ送信・保存しません。位置の履歴を外部へ送る機能はこのバージョンにありません。
  • 「Appleマップで渋滞・ナビ」を押すと、選択した目的地の座標を Appleマップへ引き渡します。本アプリが取得した現在地は引き渡しません。
  • 天気の取得では、端末内で緯度経度を気象庁の予報区コード (例: 東京地方 = 130000) と地図タイルの位置 (z/x/y) に変換し、その値だけを気象庁へ送ります (第 3 項)。生の緯度経度は送信しません。
  • 位置情報の利用を許可しない場合でも、旅程の作成・編集・閲覧を含む主要機能は利用できます (現在地の代わりに直近の記録を使う縮退表示になります)。

3. 本アプリの通信先

本バージョンのアプリが自動的に通信する先は、次の 2 つです。

  • 気象庁 (www.jma.go.jp)
    • 何のために: 天気予報・週間予報・降水確率・警報注意報・警報級の可能性・降水ナウキャスト
    • 送信される内容: 予報区コード (例 130000)、雨雲画像のタイル位置 (z/x/y)。旅程の内容は含みません
    • 発生タイミング: 天気の表示・更新時、雨雲を表示した時
  • cdn.cedarlab.dev (Cloudflare R2・米国)
    • 何のために: 地図タイル・地点 (POI) パック・経路データ・配布物一覧の静的配信
    • 送信される内容: ダウンロードするファイル名。旅程の内容・お客様を識別する情報は含みません
    • 発生タイミング: 地図の表示時、データパックの取得時

利用者の操作でAppleマップへ引き渡す情報

地図上の「Appleマップで渋滞・ナビ」を押した場合に限り、選択した訪問地点・候補・検索結果の 目的地座標を maps.apple.com へ引き渡します。旅程名、メモ、予約情報、 本アプリが取得した現在地は引き渡しません。Appleマップでの現在地、経路、渋滞情報等の 取り扱いは、「Appleマップとプライバシー」に従います。

  • 上記の自動通信と、利用者が選んだAppleマップへの引継ぎ以外の通信・データ提供は行いません。
  • いずれの通信先においても、通信の性質上、お客様の IP アドレスが相手方に到達します。
  • Cloudflare, Inc. (米国) は配信のみを担い、送信されるのはファイル名等の取得要求です。旅程・位置・識別子は含めていません。
  • 外国にある事業者による処理について: 静的データは Cloudflare, Inc. (米国) を通じて配信されます。本アプリが取得要求に付加するのはファイルのパス等で、旅程の内容や 本アプリが取得した現在地は含めません。一方で、通信の性質上、IP アドレスやユーザーエージェント等の技術情報は Cloudflare, Inc. に到達することがあります。その取り扱いはCloudflareのプライバシーポリシーに従います。

4. このバージョンで提供していない機能

TestFlight β (0.1.x) では、以下はアプリ内に存在しません。 将来のバージョンで搭載する際は、本ポリシーを改訂し、AI 機能については 利用直前に改めて同意を取得します。

  • AI 機能 (AI への相談、AI による再計画、外部で作成した旅程の取り込み) — 旅程を外部へ送信する機能はこのバージョンにありません。
  • 有料プラン (Pro) / アプリ内課金 — 購入導線・購入検証の通信ともにありません。
  • アカウント・ログイン
  • 旅程を受信・保存する開発者のサーバー — 静的データ配信用CDNは使用しますが、 旅程の内容を送信する機能はありません。

5. 気象データの出典と取り扱い

  • 本アプリの気象情報は気象庁が発表する予報・警報等を利用しています。出典: 気象庁。
  • 表示にあたっては「気象庁の予報をもとに本アプリが作成」した旨を明示します (気象庁の公共データ利用規約に基づく加工表記)。
  • 本アプリは気象庁の発表内容を改変せず表示します。発表された区域・時間区分・数値のまま出し、独自の予報値の作成 (空間内挿・時間内挿を含む) は行いません。
  • 気象データの取得は端末から気象庁のサーバーへ直接行われます。取得したデータは端末内にキャッシュされ、圏外では最後に取得できた内容を「いつ時点のものか」と併せて表示します。

6. 地図・地点データの出典

配信物ごとに出典とライセンスが異なります。アプリ内の表示と本ポリシーは同一の文言にしています。

  • 地図タイル (Protomaps) / 経路データ (オフライン経路) — 出典: OpenStreetMap (ODbL)
    • 帰属表示: © OpenStreetMap contributors (ODbL) / © Protomaps
  • 地点 (POI) データ — 出典: Overture Maps (permissive ソースのみ)
    • 詳細は下記のとおり (OpenStreetMap 由来ではありません)
  • 気象情報 — 出典: 気象庁
    • 帰属表示: 天気情報の出典: 気象庁。本アプリは気象庁の予報をもとに表示を作成しています。
  • 地図タイルと経路データは OpenStreetMap 由来 (ODbL) です。地図を表示している間は画面上に帰属表示を常時出します。
  • 地点 (POI) データは OpenStreetMap 由来ではありません。 Overture Maps のデータのうち、再配布に share-alike の義務を伴わないライセンス (CDLA-Permissive-2.0 / Apache-2.0 / CC0-1.0 / ODC-By-1.0) のソースのみを収録しています。ODbL のソースは意図的に除外しており、データ更新のたびに機械検査して混入があればビルドを停止します。

7. データの削除・持ち出し

  • 削除: iPhone からアプリを削除すると、端末上の旅程・候補・予約情報・各種キャッシュは消去されます。 事前に書き出したバックアップや iOS 標準のバックアップが利用できる場合は、そこから復元できることがあります。 開発者側に旅程データの控えは存在しないため、開発者への削除依頼は不要です。
  • 持ち出し (エクスポート): アプリ内の書き出し機能から、旅程を JSON 形式で書き出せます。書き出しには用途の選択があり、既定はバックアップ用です。
    • バックアップ用 (既定): 機種変更・端末紛失に備えた自分用の控えです。復元に必要なため、予約番号・電話番号を伏せずにそのまま含みます。第三者へ渡さないでください。
    • 共有用: 他の人やほかのアプリへ渡す用途です。予約番号・電話番号は既定で伏せます (画面のチェックで解除できます)。
  • 書き出した JSON は、いずれの用途でも端末を離れた時点で本アプリの管理外になります。
  • バックアップ: 旅程データは iOS 標準のバックアップ (iCloud バックアップ / クイックスタート) の対象です。バックアップの取り扱いは Apple のポリシーに従います。地図・経路などの再取得可能なデータはバックアップ対象外です。

8. お子さまの利用

  • 本アプリは特定の年齢層を対象としたサービスではなく、お子さま向けに設計されたもの (Apple の Kids Category) でもありません。
  • 本バージョンは本アプリから旅程や利用者情報を自動収集しません (第 1 項)。通信先に到達する技術情報や、利用者自身が送るTestFlightフィードバックについては、 第 1 項と第 3 項をご確認ください。
  • アカウント登録・課金・AI 機能・ユーザー間のやりとりのいずれも本バージョンには存在しません。

9. 安全管理措置

  • 旅程データは端末内に保存され、iOS の保護機構 (端末のパスコード・生体認証によるファイル保護) に依存します。
  • 外部との通信はすべて暗号化 (HTTPS/TLS) されます。
  • 開発者が旅程の内容を受信・保存するサーバーは、このバージョンでは使用しません。

10. 本ポリシーの変更

送信内容・送信先事業者・取得情報に変更が生じる場合は、本ポリシーを改訂し、アプリ内で告知します。 AI 機能と有料プランを搭載する際は、正式版のポリシーへ差し替え、 AI 機能の利用直前に改めて同意を取得します。
